# intent

Does the change do what its pull request description and linked plan say it does?

Compare the description's stated goal and steps with the diff. Report a stated part that's missing, done differently than described without saying why, or a significant change the description doesn't mention. Be generous with subtasks: a step done in a different but equivalent way, or split across files, counts as done.

Without a description to compare against, return no findings. Leave code quality to others.
